# Psicotécnicos originales — preguntas

Material original elaborado para esta práctica. El contenido no procede de un banco de preguntas. Elige una opción por pregunta.

## 1. Serie numérica

¿Qué número continúa la serie?

`4, 7, 13, 25, 49, ?`

A) 73  
B) 89  
C) 97  
D) 99

## 2. Matriz de símbolos

Cada fila sigue la misma transformación de izquierda a derecha. ¿Qué símbolo falta?

```text
○   △   □
△   □   ☆
□   ☆   ?
```

A) ○  
B) △  
C) ☆  
D) □

## 3. Giro de una figura

La flecha gira 90° en sentido horario en cada paso. ¿Cuál aparece en la cuarta posición?

```text
1       2       3       4
  ↑       →       ↓       ?
```

A) ←  
B) ↑  
C) →  
D) ↓

## 4. Rotación de una cuadrícula

La figura de la izquierda gira 90° en sentido horario. ¿Qué resultado corresponde?

```text
Figura inicial       A             B             C             D
┌───┬───┐          ┌───┬───┐     ┌───┬───┐     ┌───┬───┐     ┌───┬───┐
│ ● │   │          │   │ ● │     │   │   │     │ ▲ │   │     │ ● │   │
├───┼───┤          ├───┼───┤     ├───┼───┤     ├───┼───┤     ├───┼───┤
│   │ ▲ │          │ ▲ │   │     │ ● │ ▲ │     │   │ ● │     │ ▲ │   │
└───┴───┘          └───┴───┘     └───┴───┘     └───┴───┘     └───┴───┘
```

Las cuatro cuadrículas de la derecha son las opciones A, B, C y D, respectivamente.

## 5. Cubo en una red

Se pliega la red por las líneas. ¿Qué cara queda opuesta a la cara marcada `X`?

```text
        ┌───┐
        │ A │
┌───┬───┼───┼───┐
│ B │ X │ C │ D │
└───┴───┼───┼───┘
        │ E │
        └───┘
```

A) A  
B) B  
C) D  
D) E

## 6. Analogía de relaciones

Brújula es a orientación como regla es a…

A) longitud  
B) velocidad

## 7. Razonamiento con condiciones

En una fila, Leo está a la izquierda de Mara. Nerea está a la derecha de Mara. Omar está a la izquierda de Leo. ¿Quién ocupa necesariamente el extremo izquierdo entre estas cuatro personas?

A) Leo  
B) Mara  
C) Nerea  
D) Omar

## 8. Cálculo de trabajo

Una máquina etiqueta 84 paquetes en 7 minutos, siempre al mismo ritmo. ¿Cuántos paquetes etiqueta en 12 minutos?

A) 126  
B) 132  
C) 144  
D) 168

## 9. Código alfabético

En un código, cada letra se sustituye por la siguiente letra del alfabeto español, considerando `Ñ` entre `N` y `O` (por ejemplo, `N → Ñ`, `Ñ → O`, `Z → A`). ¿Cómo se codifica `TREN`?

A) `USFO`  
B) `USFÑ`  
C) `VSGO`  
D) `USGO`

## 10. Conteo visual

¿Cuántos cuadrados hay en el dibujo? Cuenta los cuadrados pequeños y cualquier cuadrado mayor formado por ellos.

```text
┌─────┬─────┐
│     │     │
├─────┼─────┤
│     │     │
└─────┴─────┘
```

A) 4  
B) 5  
C) 6  
D) 8
