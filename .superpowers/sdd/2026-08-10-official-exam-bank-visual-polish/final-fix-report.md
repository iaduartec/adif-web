## Finding resolution

1. **Supabase fail-closed boundary**
   - Added one shared runtime-config boundary.
   - The in-memory identity/store is available only when `PLAYWRIGHT_TEST === "true"`.
   - Missing production configuration throws a clear error naming both required variables.
   - Mock-store initialization is lazy, and Playwright explicitly injects its flag into the web server/client build.

2. **Public official-content DTOs**
   - Practice and historical-exam client props now use explicit public DTOs.
   - Public payloads exclude `answer`, `source.fingerprint`, and answer-derived values.

3. **Validated, atomic simulation submission**
   - Server input accepts only `A`–`D`, known exam question IDs, and safe integer elapsed times from 0 through 86,400,000 ms.
   - Parent attempt and answer rows are persisted by one authenticated, `auth.uid()`-owned transactional RPC.
   - The migration independently checks row shape, allowed answers, uniqueness, result counts, elapsed range, and `correct - incorrect / 3` scoring.
   - Generated Supabase TypeScript contracts and the Playwright mock RPC were updated.

4. **Legacy session removal**
   - Removed `?module=` links, legacy question adapters/filtering, and the synthetic `SIM-01` fallback.
   - English and psychometric pages no longer advertise unrelated official practice sessions; supported navigation points to published historical exams.
   - Lesson practice guidance links only to the official bank and states that no unpublished lesson mapping is implied.

5. **Server-first lesson rendering**
   - `LessonReader` is a server component; tab selection and official-text search use URL parameters.
   - The legal full-text aggregate was removed. Per-document dynamic imports run only when `full=true` is explicitly requested.
   - Legal content stays server-rendered; a lightweight client shell handles progress/save behavior. Existing summaries, concepts, examples, takeaways, references, and error guidance remain rendered.

6. **Accessible exam-submission dialog**
   - Reused shared modal focus management for focus entry, tab trapping, Escape dismissal, scroll lock, and focus restoration.
   - Background runner content becomes inert and `aria-hidden` while the modal is open.
   - Component and Playwright coverage exercise entry, Escape, and restored focus.

7. **Importer rejection accounting**
   - Unexpected `specific_part` question numbers are rejected against the manifest and counted in each model result.

8. **Europe/Madrid streaks**
   - Activity and streak keys now use `Europe/Madrid` calendar dates with DST-safe day shifting.

9. **Pagination bounds**
   - Requested pages clamp to the available range.
   - Disabled previous/next controls render without links and expose `aria-disabled`.

10. **Generated TypeScript cache hygiene**
    - Confirmed `tsconfig.tsbuildinfo` is generated by incremental TypeScript.
    - Removed it from the index and added it to `.gitignore`; the physical generated cache remains ignored.
